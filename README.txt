US, SOMEHOW — Friendship Anniversary Website

This folder contains the updated friendship anniversary website with all 22 approved letters, the separate 10 floating Memory clouds, the scrapbook-style envelope interaction, and local MP3 tracks.

HOW TO OPEN
1. Extract the ZIP file.
2. Keep the music folder beside index.html.
3. Open index.html in a modern browser (Chrome, Edge, Firefox, or Safari).
4. Start the experience with the on-page button. Browsers require a user interaction before audio can begin.

MUSIC
- Risk It All plays from the opening pages.
- Gift of a Friend takes over in the letters section and continues through the ending.
- The audio files are included locally in the music folder, so playback does not depend on YouTube embeds.

MEMORIES
- The 22 numbered envelopes open the full approved letters.
- The 10 floating Memory clouds are a separate feature and do not replace the letters.
- The site is a local keepsake website; it is not hosted online by this ZIP.
